# Careers fair poster

A2 portrait poster for the litigation trainee programme at Thomas Philip, for
careers fairs. Same facts and look as the LinkedIn ad
(`video/linkedin-trainee-ad/`): navy and cream, Playfair Display and Source
Sans 3, nothing the programme does not actually offer.

- `poster.html` is the source, 1191 by 1684 (A2 at 72 points per inch),
  imported into Adobe Express, where it is edited and printed from.
- `preview.png` is a render of it. The fonts load from Adobe Fonts, so a
  local render without them uses stand-ins.
- The QR code goes to https://litigation-training.vercel.app/trainee.

Change it when the start date, the weeks or the sign-up address change.
