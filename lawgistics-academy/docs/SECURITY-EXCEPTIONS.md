# Security exceptions

Every time a security control is relaxed, it is recorded here first, under
the rules in `docs/ROLLBACK.md`, "When a security control may be relaxed".
A row is added before the exception starts and completed when it ends. Rows
are never deleted or changed afterwards; a mistake is corrected in a new row.
