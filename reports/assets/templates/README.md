# Four card templates

Same navy `#141A28`, same cream `#EDE7DC`, same Playfair Display and TikTok Sans, same hairlines, same kicker and wordmark. Only the layout changes. Rotate them and the grid stops looking like one repeated tile.

Generator: `tools/carousel/templates.py`. Sample cards: `template-1.png` to `-4.png`.

| # | Name | Layout | Use it for |
|---|---|---|---|
| A | Headline | Statement centred in the well, body under | The default. Facts, rulings, anything narrative. |
| B | Number | One huge Playfair numeral, serif label, sans line under | Sentences, damages, dollar figures, volumes, dates, counts. Any post with one number that carries the story. |
| C | Quote | Oversize opening mark on its own line, then serif italic quote, attribution under | Judicial quotes, statutory phrases, anything worth reading in the judge's own words. |
| D | Air | Short line hard at the top, deliberate empty space below | Disclaimers, single-idea slides, closers, the "nothing has been decided" slide. The space is the point. |

## How to rotate them

Within a carousel, do not use the same template twice in a row. A five slide case deck works well as **A, B, A, C, D**.

Across the grid, vary which template becomes slide 1, since that is the tile people see. B and D make the strongest thumbnails because they have the least text.

## Rules that do not change

- Kicker top left, citation bottom left, wordmark bottom right, `swipe →` on slide 1.
- Slide numbering `01 / 05` top right.
- No em dashes. No page decoration. No comment bait.
- Alternate navy and cream at post level so the grid keeps its checkerboard.
- Template B: only one number, and it has to be the number the post is about. Do not use it decoratively.
- Template D: resist filling the space. If it needs more words it is not a D.
